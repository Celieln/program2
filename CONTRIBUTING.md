# Contributing

Kami menerima kontribusi! Berikut panduannya.

## Cara Berkontribusi

1. **Fork** repository ini
2. Clone fork ke lokal
3. Buat branch baru: `git checkout -b fitur/nama-fitur`
4. Lakukan perubahan, lalu commit dengan pesan yang jelas
5. Push dan buat **Pull Request**

## Guidelines

- Gunakan pesan commit yang jelas (conventional commits)
- Jangan commit file sensitif (config, credentials, database)
- Uji perubahan di lingkungan lokal sebelum membuat PR

Terima kasih sudah berkontribusi!
